# Code of Conduct

## Our Standards

This is a small project maintained by a small team for a small clinic. We keep it simple:

- Be professional
- Don't be a problem
- If something's broken, fix it or flag it — don't pretend you didn't see it
- If you broke something, say so immediately. No shame, just honesty.
- The client is a real business with real patients. Keep that in mind.

## Scope

This applies to all project spaces: the repo, any related communications, and production deployments. Yes, production deployments. Clicking "delete all" on WP Reset at 2am counts as a code of conduct violation.

## Enforcement

There's one team. If there's a problem, we talk about it like adults.

For security issues specifically, see [SECURITY.md](SECURITY.md).
